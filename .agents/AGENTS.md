# Project Rules

## Communication & Copywriting Style
- **Solo Project Directive**: Never use plural pronouns or team-oriented words such as "uns", "unsere", "unser", "wir", "our", "us", "we". The website and 3D printing shop is a solo project operated by a single person. Always write from a 1st person singular ("ich", "meine") or neutral/descriptive perspective ("die TOP 3 Empfehlungen", "das High-End Highlight").
